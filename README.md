# Cryptid Hunter

A Godot 4 game project.

## Getting started

1. Install [Godot 4.4+](https://godotengine.org/download) (standard build, not .NET).
2. Clone this repo: `git clone https://github.com/benevolio1/Cryptid-Hunter.git`
3. Open Godot, click **Import**, and select `project.godot` in the cloned folder.
4. Press **F5** to run. Move the player with **WASD**.

## Layout

- `scenes/` – scene files (`main.tscn` is the entry scene)
- `scripts/` – GDScript files
- `assets/` – art, audio, fonts
